# Secret Gyfter - Fruit Edition 🎁🍎

A simple React.js website that takes in the user's name and randomly allocates them a fruit!

## Features

- Clean, responsive user interface
- Name input with form validation
- Random fruit allocation from 10 different fruits:
  - 🍎 Apple
  - 🍌 Banana
  - 🍊 Orange
  - 🍇 Grapes
  - 🍓 Strawberry
  - 🍉 Watermelon
  - 🍑 Peach
  - 🍍 Pineapple
  - 🥝 Kiwi
  - 🥭 Mango
- Smooth animations and transitions
- Dark/light mode support
- "Try Again" functionality to get a new fruit

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/jenngynn/secretgyfter.git
cd secretgyfter
```

2. Install dependencies:
```bash
npm install
```

### Running the Application

Start the development server:
```bash
npm run dev
```

Open your browser and navigate to `http://localhost:5173/`

### Building for Production

Create a production build:
```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```

## Usage

1. Enter your name in the input field
2. Click the "Get My Fruit!" button
3. See which fruit you've been randomly assigned
4. Click "Try Again" to reset and get a new fruit

## Technology Stack

- **React** - UI library
- **Vite** - Build tool and dev server
